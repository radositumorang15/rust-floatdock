# Grimoire Theme Pack (FloatDock)

Tema orisinal bertema sihir mana elemental yang dirancang untuk keindahan visual tingkat tinggi tanpa melanggar hak cipta karya apa pun.

## Struktur Theme Pack
```
themes/grimoire/
├── theme.json        # Konfigurasi visual tema, warna aksen, efek
├── wall.jpg          # (Opsional) Wallpaper pengguna sendiri
├── icons/            # (Opsional) Ikon custom aplikasi (.svg / .png)
└── sounds/           # (Opsional) Efek audio klik / hover (.wav / .mp3)
```

## Atribut Mana yang Didukung
Anda dapat memilih atribut elemen mana di pengaturan:
- 🍃 **Angin (Wind)**: `#7CFFB2` (Hijau Mana Zamrud)
- 🔥 **Api (Fire)**: `#FF5757` (Merah Membara)
- 💧 **Air (Water)**: `#5BE2FF` (Biru Laut Terang)
- 🪨 **Bumi (Earth)**: `#E5B869` (Emas Keemasan)
- ⚡ **Cahaya (Light)**: `#FFE66D` (Kuning Berpendar)
- 🔮 **Kegelapan (Dark)**: `#A855F7` (Ungu Mistik)

## Cara Pasang Tema Custom Milik Anda Sendiri
1. Salin folder tema ini ke `%APPDATA%\FloatDock\themes\<nama-tema-anda>\`
2. Letakkan gambar wallpaper Anda sebagai `wall.jpg`.
3. Buka **Pengaturan Float Dock** (Klik kanan dock -> Pengaturan) dan pilih tema Anda.
